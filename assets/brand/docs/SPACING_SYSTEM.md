# Spacing System

La unidad base es 4 px. Esta base permite densidad empresarial, alineación precisa con iconos de 16/20/24 px y adaptación limpia a documentos.

| Token | Valor | Uso |
| --- | ---: | --- |
| space-0 | 0 px | Sin separación |
| space-1 | 4 px | Separación interna mínima |
| space-2 | 8 px | Agrupación compacta |
| space-3 | 12 px | Padding compacto |
| space-4 | 16 px | Padding estándar |
| space-5 | 20 px | Separación media |
| space-6 | 24 px | Gutter estándar |
| space-8 | 32 px | Bloques y paneles |
| space-10 | 40 px | Separación de grupos |
| space-12 | 48 px | Secciones compactas |
| space-16 | 64 px | Secciones web |
| space-20 | 80 px | Separación editorial controlada |
| space-24 | 96 px | Máximo de sección |

Áreas táctiles mínimas: 44 px. Controles: 32 px compacto, 40 px estándar, 48 px cómodo.
