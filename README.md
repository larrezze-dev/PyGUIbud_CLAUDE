A drag-and-drop GUI designer for **ttkbootstrap** (with tkinter and PySide6 back-ends) that saves
portable `.ui` files. Load a `.ui` file at run time with `pyguibud-runtime`, or turn it into a
plain Python module with `pyguibud-uic`.

![Demo: a Label and a Button are dragged from the palette onto a new main window, the button gets a text and the handler on_hello, the form is saved as hello.ui and run, and clicking the button changes the label](https://raw.githubusercontent.com/larrezze-dev/PyGUIbud_CLAUDE/master/docs/images/demo.gif)

## Install
Python 3.10–3.13. On Linux, install Tk first (`sudo apt install python3-tk`).

```bash
pip install pyguibud          # pip
uv tool install pyguibud      # uv: the pyguibud and pyguibud-uic commands
uvx pyguibud                  # uv: run the designer without installing
```

Add the `[pyside]` extra (`pip install "pyguibud[pyside]"`) for the PySide6 back-end. See the
[full install guide](https://github.com/larrezze-dev/PyGUIbud_CLAUDE/blob/master/docs/install.md).

## Quick start
```bash
pyguibud                                 # open the designer
pyguibud-uic --check form.ui             # validate a .ui file
pyguibud-uic form.ui                     # generate the Python module form_ui.py
pyguibud-uic form.ui -o my_form.py       # ... or choose the output name with -o
pyguibud-uic --extract form.ui -o form.pot   # extract the strings for translators
```

```python
from pyguibud_runtime import load_ui


class Handlers:
    def on_quit(self) -> None:
        ui.destroy()


ui = load_ui("form.ui", Handlers())
ui.run()
```

`load_ui(path, handlers=None, *, strict=True, backend="ttkbootstrap", master=None, lang=None,
localedir=None, translator=None)` accepts `backend="ttkbootstrap"` (the reference),
`"tkinter"` or `"pyside6"`. Code generated by `pyguibud-uic` does not import PyGUIbud.
Applications that only load `.ui` files need just
[`pyguibud-runtime`](https://pypi.org/project/pyguibud-runtime/).

## Features
- Drag widgets from a palette onto a canvas; move, resize and reparent them there or in the
  object tree. Multi-select, copy/paste (also between files), undo/redo for every change.
- Property inspector with typed editors, grid and pack layout editing, menu editor, event
  handlers, and variables bound to widgets.
- Main windows, dialogs and reusable components (`<include>`), with templates for new files.
- Live preview in a separate process, with a live theme and language switch, plus a pseudo-locale
  (`en_XA`) to check text expansion.
- Keyboard-only operation, autosave with crash recovery, and an unsaved-changes guard.
- Invalid actions are blocked with a translated reason rather than silently applied.
- Saving is atomic and keeps a backup. Corrupt, oversized or newer-schema files are refused. A
  `.ui` file holds no code; only the widget plugins you have installed run.
- A versioned, validated `.ui` XML format.

Not in v0.1.0: the font editor, which is deferred until after v1.

## Supported toolkits
| Back-end | Toolkit | Licence |
| --- | --- | --- |
| `ttkbootstrap` (reference) | [ttkbootstrap](https://github.com/israel-dryer/ttkbootstrap) | MIT |
| `tkinter` | tkinter, from the Python standard library | PSF |
| `pyside6` | [PySide6](https://pypi.org/project/PySide6/), optional `[pyside]` extra | LGPL-3.0 |

PyGUIbud depends on ttkbootstrap. PySide6 is never bundled: it is imported from your environment
only if you install the extra. Thanks to the authors of all three.

## Languages
The designer is available in British English, Spanish (Spain), Portuguese (Portugal and Brazil),
German, Italian, Dutch and French, with a live language switch.

## Plugins
Widgets can be added through the `pyguibud.widgets` entry point, and a crashing plugin shows as a
placeholder instead of taking the designer down. See the
[example plugin](https://github.com/larrezze-dev/PyGUIbud_CLAUDE/tree/master/examples/acme_plugin)
and
[ADR-004](https://github.com/larrezze-dev/PyGUIbud_CLAUDE/blob/master/docs/adr/ADR-004-widget-plugins.md).
