## LinkedIn (limit 1300; hand-count about 1,080)

```text
I have just released PyGUIbud 0.1.0, an open-source drag-and-drop GUI designer for Python.

It targets ttkbootstrap, with tkinter and PySide6 back-ends. You lay out a window on a canvas, save it as a portable .ui file (versioned, validated XML), and then either load that file at run time or generate a plain Python module with pyguibud-uic.

What is in it: a palette and canvas, an object tree, a property inspector, grid and pack layout editing, a menu editor, undo/redo, keyboard-only operation, autosave with crash recovery, and live preview with language and theme switching. The designer is available in eight languages.

A .ui file holds no code, and invalid actions are blocked with an explanation instead of being applied silently. Not in 0.1.0: the font editor.

Thanks to the authors of ttkbootstrap, tkinter and PySide6, which PyGUIbud builds on.

Created by me and programmed with the support of Claude Code. Issues and feedback are welcome.

MIT licence. Source and install instructions: https://github.com/larrezze-dev/PyGUIbud_CLAUDE

#Python #tkinter #OpenSource
```
